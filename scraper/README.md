# Polite Scraper 

## Target Classification

- **Target Site:** Books to Scrape (https://books.toscrape.com/)
- **Why:** It is a public sandbox site built specifically for practicing web scraping legally and safely.
- **Scope:** Restricted strictly to the first 3 catalogue pages only (60 books total).
- **Data Collected:** Book titles, product URLs, raw price text, numeric prices (GBP), availability status, ratings, optional descriptions, source page provenance, and fetch timestamps.
- **Robots.txt Result:** No robots file found (or checked via `https://books.toscrape.com/robots.txt`).
- **Appropriateness:** This is appropriate because the site explicitly welcomes scrapers for educational purposes without impacting production services.

I will not reuse this code on another site without checking its rules and terms first[cite: 1].
